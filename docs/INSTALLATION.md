# Installation

Use the [Homebrew installation and upgrade instructions](../README.md#installation).
The cask installs for the current user, preserves GSettings preferences, and does not
modify or restart knocker.service. Move any existing manual extension directory to
a backup before the first Homebrew install. Uninstall with `brew uninstall --cask knocker-gnome`.

For source development, see [development](DEVELOPMENT.md).
