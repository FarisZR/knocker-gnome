# Contributing

See [development](docs/DEVELOPMENT.md) for setup, verification and local installation,
[architecture](docs/ARCHITECTURE.md) for module ownership, and
[release automation](docs/PUBLISHING.md) for packaging and publishing.

Keep intended behavior compatible with the GNOME versions in metadata.json. Add
behavior regression checks when changing lifecycle, commands or protocol parsing.
Run lint, tests and the headless Shell check before submitting a pull request.
